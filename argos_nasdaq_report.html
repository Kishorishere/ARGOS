The one finding — symmetric debate across four markets

Bull–Bear confidence gap tracks the market, not the models. Range: 0.260 to 0.009.

The earlier NEPSE run showed Bear systematically 0.30+ points hotter than Bull on 43 of 44 dates — a provider prior. The router was rewritten so both advocates share gpt-4o at the same temperature with the same fallback chain; tests/test_openai_router.py asserts this invariant at import. Across four 2024 markets with the same router, the confidence gap now scales smoothly with evidence one-sidedness.

Methodology & caveats

  • Universe. NVDA (AI-datacentre), TSLA (robotaxi narrative), ORCL (OCI/AI cloud), and KO (Coca-Cola, legacy consumer-staples control — zero AI exposure). KO was added specifically to test whether the pipeline's accuracy survives on a boring name — it does.
  • Portfolio. $4,000 total paper book, $1,000 initial per ticker, independent books per name (so Sharpe is per-ticker and directly comparable).
  • Kronos. Live for every decision this run (NeoQuasar/Kronos-small on CUDA via Colab Cloudflare tunnel). 10-bar forecast per date; direction score and short/swing-horizon % moves feed the ensemble log-odds combination.
  • Token tracking. Per-call callback captures usage_metadata on on_llm_end, attributes to the invoking agent, aggregates per decision into the journal. All tokens are gpt-4o or gpt-4o-mini (OpenAI primary); fallback-chain tokens are counted the same way.
  • Directional accuracy. BUY correct at h if next-h close-to-close return > 0; SELL correct if < 0. HOLD excluded (that's the coverage figure).
  • Look-ahead risk. OHLCV loader hard-fails on any bar dated after as_of_date. gpt-4o was trained through 2024, so fundamentals and sentiment agents may have implicit knowledge of 2024 corporate events when reasoning as of a 2024 date — stated, not hidden.
  • Simulator fees. Still using the "Nepal retail" fee model (0.40% commission + 0.015% SEBON + 7.5% CGT on wins). Over-charges a US-equity book slightly; corrected number would be ~0.1-0.3% lower drag.
