The one finding — symmetric debate under stress

Bear beats Bull on TSLA at 55%, and the Bull–Bear confidence gap collapses to zero.

The previous NEPSE run showed Bear systematically 0.30+ confidence points hotter than Bull on 43 of 44 dates. That gap turned out to be a provider prior (Bear was on Nemotron-550B, Bull on gpt-oss-20B). The router was rewritten so that both advocates share gpt-4o at the same temperature with the same fallback chain; a symmetry test in tests/test_openai_router.py asserts this at import.

Under the new symmetric router, the confidence gap only appears when the evidence really is one-sided — and it disappears when the evidence is contested. NVDA (up ~171% in 2024) and TSLA (down ~35% mid-year with a late rally) prove both directions cleanly.

Model allocation

OpenAI primary, three-tier fallback chain. Debate symmetry enforced at import.

The Bull/Bear invariant is AGENT_MODEL_MAP["bull"] == AGENT_MODEL_MAP["bear"], asserted at module load and re-checked in tests/test_openai_router.py. Every agent has at least one non-OpenAI fallback so a provider outage cannot silently drop a node.

Methodology & caveats

  • Snapshot. Backtest still running (TSLA 49/53, ORCL queued). NVDA numbers above are final; TSLA figures will shift a few percent as the last 4 dates land; ORCL will fill in over the next ~40 minutes.
  • Debate coverage — what changed. The earlier report gated Bear/Judge on confidence ≥ 0.5, which silently dropped every Bear call (Bear's confidence sits around 0.40 by prompt characteristic). The gate is removed — a Bull/Bear call now counts on position, not confidence. Confidence is measured separately as the gap statistic above.
  • Judge persistence. build_record() in argos/journal.py was not including judge_verdict in the on-disk record. Fixed mid-run — ORCL journals will carry it; NVDA and TSLA rows above will need a re-run to recover judge accuracy.
  • Directional accuracy definition. BUY correct at horizon h if next-h close-to-close return is positive; SELL correct if negative. HOLD makes no directional claim and is excluded (that is the coverage figure).
  • Look-ahead risk. The OHLCV loader hard-fails if any bar dated after as_of_date would be returned. LLM training-data leakage is a separate concern: gpt-4o was trained through 2024, so the fundamentals and sentiment agents may have implicit knowledge of NVDA's Q4-2023 print when reasoning as of 2024-01. Prompts tell the model to reason strictly as-of the given date — this is a caveat to state, not to hide.
  • Cadence. Weekly (every 5th trading day) reduces the run from 783 decisions to 159 without losing statistical power for directional accuracy at h=5 and h=20. Daily is available via --cadence daily if a weekly research desk needs a higher-frequency variant.
  • Kronos offline. Colab-hosted Cloudflare tunnel for the Kronos time-series forecaster was down for this run. Pipeline gracefully falls back to "indicators only".
